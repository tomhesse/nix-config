# Keybinds

`Super` = Windows key

## Applications

| Key | Action |
|-----|--------|
| `Super + Shift + Return` | Terminal (kitty) |
| `Super + P` | App launcher (rofi) |
| `Super + Shift + P` | Power menu |
| `Super + Shift + L` | Lock screen |
| `Super + V` | Clipboard history |
| `Print` | Screenshot (region) |

## Named Workspaces

| Key | Focus | Move window |
|-----|-------|-------------|
| `Super + B` | Browser | `Super + Shift + B` |
| `Super + E` | Editor | `Super + Shift + E` |
| `Super + C` | Chat | `Super + Shift + C` |
| `Super + G` | Gaming | — |
| `Super + Shift + G` | Launcher | — |
| `Super + Shift + M` | Music (special) | — |
| `Super + Shift + O` | Notes (special) | — |

## Numbered Workspaces

| Key | Action |
|-----|--------|
| `Super + 1-9, 0` | Focus workspace 1–10 |
| `Super + Shift + 1-9, 0` | Move window to workspace 1–10 |
| `Super + Tab` | Previous workspace |

## Window Management

| Key | Action |
|-----|--------|
| `Super + Shift + Q` | Close window |
| `Super + F` | Toggle float |
| `Super + M` | Fullscreen |
| `Super + Return` | Swap with master |

## Layout (Master)

| Key | Action |
|-----|--------|
| `Super + J` | Focus next |
| `Super + K` | Focus previous |
| `Super + I` | Add master |
| `Super + D` | Remove master |
| `Super + H` | Shrink master |
| `Super + L` | Grow master |

## Monitors

| Key | Action |
|-----|--------|
| `Super + ,` | Focus monitor left |
| `Super + .` | Focus monitor right |
| `Super + Shift + ,` | Move window to monitor left |
| `Super + Shift + .` | Move window to monitor right |

## Mouse

| Key | Action |
|-----|--------|
| `Super + LMB` | Drag window |
| `Super + RMB` | Resize window |

## Media Keys

| Key | Action |
|-----|--------|
| `XF86AudioMute` | Mute |
| `XF86AudioPlay` | Play / Pause |
| `XF86AudioStop` | Stop |
| `XF86AudioPrev / Next` | Previous / Next |
| `XF86AudioRaiseVolume / LowerVolume` | Volume up / down |
| `XF86MonBrightnessUp / Down` | Brightness up / down |
